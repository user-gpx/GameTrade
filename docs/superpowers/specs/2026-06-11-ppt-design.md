## 图表生成方案

- 使用 Draw.io XML 格式 (.drawio) 创建：用例图、活动图、类图、时序图、状态图
- PPT 通过 python-pptx 生成 .pptx 文件
- 图表以 Draw.io 源文件保存，PPT 中嵌入图片占位符

## 技术实现

- PPT 生成脚本：Python + python-pptx 库
- 图表：手动编写 Draw.io XML（mxGraph 格式）
- 输出位置：课设汇报/GameTrade课程设计汇报.pptx
